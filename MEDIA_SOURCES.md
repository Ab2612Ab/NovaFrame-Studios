# NovaFrame media sources

The upgraded concept uses externally hosted interactive/media references rather than bundling large video files into the repository.

## Interactive 3D

- Spline Viewer is loaded from the official Spline viewer package.
- Scene reference: `https://prod.spline.design/9951u9cumiw2EhJ8/scene.splinecode`
- Spline is used for browser-based real-time 3D interaction, animation and responsive scenes.

## Motion references

- 3D motion reference: Vimeo video `733560561` — embedded as a background preview.
- 2D animation reference: Vimeo video `1131407948` — embedded as a background preview.

These embeds are intentionally external so the portfolio stays lightweight. Before using any third-party media in a commercial client project, replace the references with assets for which the project owner has the appropriate usage rights.

## Design direction

The interaction model is inspired by the reference provided by the project owner: layered depth, pointer-responsive composition, interactive 3D scenes, motion-led storytelling, and animated 2D graphics. The implementation is an original NovaFrame interface rather than a copy of the reference site.
