# NovaFrame Studios

Premium cinematic animation studio website for **NovaFrame Studios**.

> Transforming Ideas Into Living Stories.

## Included

- Cinematic responsive landing page
- Animated hero artwork built with CSS
- Selected work / case-study showcase
- Animation and motion-design service grid
- Four-step creative process
- Mobile navigation
- Contact CTA with email action
- SEO metadata and branded favicon
- Responsive layouts for mobile, tablet and desktop

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Production

```bash
npm run build
npm start
```

The project is structured as a lightweight Next.js application and can be deployed to Vercel or another Node-compatible hosting provider.
